만들고 싶은 계산기나 도구를 남겨 주세요. 글은 이 브라우저에 저장됩니다.

삼각함수, 로그, 제곱, 제곱근, 괄호를 지원하는 공학용 계산기입니다. DEG/RAD를 전환할 수 있습니다.

0

간단한 사용법

  • 숫자와 +, -, ×, ÷ 를 누른 뒤 = 로 계산합니다.
  • sin, cos, tan은 각도 모드를 먼저 고르세요. DEG는 360도, RAD는 라디안입니다. 예: 90 → sin → = 이면 1입니다.
  • log는 상용로그(10), ln은 자연로그(e)입니다. 예: 100 → log → = 이면 2입니다.
  • √ 는 제곱근, x²는 제곱, x^y는 거듭제곱입니다. 2 → x^y → 10 → = 이면 1024입니다.
  • 1/x는 역수, n!는 팩토리얼입니다. π와 e는 상수를 넣습니다.
  • 괄호 ( ) 로 연산 순서를 바꿀 수 있습니다. AC는 전체 지움, ← 는 한 글자 지움입니다.

지정한 시각에 브라우저 알림과 소리를 울립니다. 탭을 열어 두세요.
