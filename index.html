카시오 공학용 계산기 완벽 사용 가이드

📐 1. 각도 단위 설정 (DEG / RAD / GRAD)

  • DEG (Degree, 도): 원 한 바퀴를 360도로 나타내는 기본 각도 모드입니다. (예: sin(30) = 0.5, cos(60) = 0.5)
  • RAD (Radian, 라디안): 공학 및 수학의 표준 각도 단위입니다. 2π rad = 360°. (예: sin(π÷2) = 1)
  • GRAD (Gradian, 그라디언): 1 직각을 100그라드로 정의하는 단위입니다. (예: sin(100) = 1)
  • ※ 삼각함수 계산 전 원하는 각도 단위를 상단 탭에서 먼저 확인하세요.

🔄 2. SHIFT 및 HYP (2차 기능 키)

  • SHIFT: 누르면 상단 S 표시등이 켜지며 버튼 위 노란색 2차 기능(sin⁻¹, cos⁻¹, tan⁻¹, eˣ, 10ˣ, x³, ʸ√x, ∛, Ran#, 1/x)이 활성화됩니다. 사용 후 자동 복귀합니다.
  • HYP: 쌍곡선함수(sinh, cosh, tanh)를 사용합니다. SHIFT와 함께 누르면 쌍곡선 역함수(asinh, acosh, atanh)를 계산합니다.

🔢 3. 삼각함수 & 역삼각함수

  • sin, cos, tan: 기본 삼각함수. 각도 모드에 따라 입력값을 처리합니다.
  • sin⁻¹ (arcsin), cos⁻¹ (arccos), tan⁻¹ (arctan): 삼각비 값을 각도로 환산합니다. (예: DEG 모드에서 sin⁻¹(0.5) = 30°)
  • sinh, cosh, tanh: 지수함수 기반의 쌍곡선 삼각함수입니다.

⚡ 4. 지수 · 로그 · 거듭제곱근

  • x², x³: 현재 수의 제곱 및 세제곱 (예: 5² = 25, 3³ = 27)
  • xʸ: 임의 거듭제곱 (예: 2^10 = 1024, 3^4 = 81)
  • √, ∛: 제곱근 및 세제곱근 (예: √(16) = 4, ∛(27) = 3)
  • ʸ√x: 임의의 y제곱근 (예: 3 yroot 8 = 2)
  • log, ln: 밑이 10인 상용로그(log)와 밑이 e인 자연로그(ln) (예: log(100) = 2, ln(e) = 1)
  • 10ˣ, eˣ: 10과 e의 거듭제곱 지수함수 (예: 10ˣ(3) = 1000)

🎲 5. 순열(nPr) · 조합(nCr) · 팩토리얼(n!)

  • nPr (순열): n개 중 r개를 택해 순서대로 나열하는 가짓수 (예: 5 P 2 = 20)
  • nCr (조합): n개 중 순서에 상관없이 r개를 택하는 가짓수 (예: 5 C 2 = 10)
  • n! (팩토리얼): 1부터 n까지의 곱 (예: 5! = 120, 0! = 1)
  • Ran#: 0 이상 1 미만의 난수(Random Number)를 생성합니다.

💾 6. Ans & 메모리 기능 (MC / MR / M- / M+)

  • Ans (Answer): 직전 계산의 최종 결과를 불러옵니다. 계산 완료 후 사칙연산자(+, -, ×, ÷)를 바로 누르면 자동으로 Ans + 형태로 이어집니다.
  • M+ / M-: 현재 화면의 계산 결과를 메모리에 더하거나 뺍니다.
  • MR (Recall): 메모리에 누적 저장된 값을 현재 수식에 삽입합니다.
  • MC (Clear): 메모리를 0으로 초기화합니다. (메모리에 값이 있으면 상단에 M이 점등됩니다.)

⚙️ 7. 공학 표기(×10ˣ), 절댓값(|x|), 나머지(mod), 역수(1/x)

  • ×10ˣ (EXP): 공학 지수 표기법 (예: 3 ×10ˣ 6 = 3,000,000)
  • |x| (Abs): 수의 부호를 양수로 바꾸는 절댓값 (예: |-7.5| = 7.5)
  • mod: 나눗셈 연산의 나머지 (예: 17 mod 5 = 2)
  • 1/x (⁻¹): 역수 연산 (예: 4의 역수 = 0.25)
  • ±: 부호 반전 (양수 ↔ 음수 전환)

⌨️ 8. PC 키보드 단축키 지원

  • 숫자패드 및 숫자키 0 ~ 9, .: 숫자 바로 입력
  • 사칙연산 +, -, *, /: 연산자 입력
  • 계산 실행: Enter 또는 =
  • 한 글자 지우기 (DEL): Backspace
  • 전체 지우기 (AC): Escape 또는 c
  • 거듭제곱: ^ / 괄호: ( , )

📊 1. 체질량지수(BMI) 계산 공식 및 단계별 기준

  • 공식: BMI = 체중(kg) ÷ [신장(m) × 신장(m)]
  • 저체중: 18.5 미만 / 정상 체중: 18.5 ~ 22.9

💡 2. BMI 지수 해석 시 유의사항

  • 서구권(WHO 글로벌 기준 비만 30 이상)과 달리 한국인을 포함한 아시아인은 같은 BMI에서도 내장지방과 대사질환 위험이 높아 BMI 25.0 이상을 비만으로 판정합니다.

    ⚖️ 렌주룰(Renju Rule)이란?

    오목은 먼저 두는 흑(선공)이 절대적으로 유리하여, 연구된 필승 수순을 막기 위해 흑에게만 금수(Foul) 제약을 둔 국제 공인 규칙입니다. 백은 아무 제약이 없으며, 흑이 금수 자리에 놓거나 장목을 만들면 백의 즉시 승리가 됩니다.

    🚫 흑의 3가지 금수 규정
    • 삼삼(3-3) 금수: 한 수로 동시에 2개 이상의 열린 3(활삼)을 만드는 수.
    • 사사(4-4) 금수: 한 수로 동시에 2개 이상의 4를 만드는 수.
    • 장목(Overline): 돌이 6개 이상 일렬로 놓이는 수 (백은 6목 이상도 승리로 인정).
    • 예외: 5목을 완성하는 수는 금수 판정보다 우선하여 흑의 즉시 승리가 됩니다.
    ⚔️ 실전 필승 비법: 4-3 공격

    오목의 가장 기본적이면서 강력한 필승 공식은 4-3(포쓰리) 양수겸장입니다. 상대방이 막아야 하는 외통 4와 한 수를 더 두면 막을 수 없는 열린 3을 동시에 만들면 상대방은 둘 중 하나만 막을 수 있어 다음 턴에 5목이 완성됩니다.

    Q2. 환갑, 칠순, 팔순은 만 나이와 세는나이 중 어떤 기준으로 계산하나요?

    환갑(회갑)은 60갑자가 돌아오는 해이므로 출생연도+60년(만 60세 생일, 세는나이 61세)에 기념합니다. 반면 칠순(고희)과 팔순(산수)은 한국 전통 가족 문화에 따라 세는나이 70세(출생연도+69년, 만 69세)와 80세(출생연도+79년, 만 79세)에 챙기는 것이 일반적이며, 일상툴 환갑·칠순 계산기에서 두 기준을 모두 비교할 수 있습니다.

    Q3. 연봉 실수령액 계산 시 비과세 식대 20만 원이 왜 중요한가요?

    비과세 식대(월 최대 20만 원)에는 4대보험과 근로소득세가 부과되지 않습니다. 동일한 세전 연봉이라도 비과세 식대가 분리되어 있으면 과세표준이 낮아져 매월 실수령액이 약 2만 5천 원~4만 원가량 증가합니다.

    Q4. 특정 계산기 페이지 주소를 단톡방이나 블로그에 바로 링크할 수 있나요?
