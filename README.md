# 일상툴

한국 검색 수요가 큰 일상 계산·변환 도구 20가지를 한곳에 모은 웹사이트입니다. 계산은 브라우저에서만 처리합니다.

## 도구 20가지

검색량이 큰 10개(추가분)와 기존 10개입니다.

1. 계산기
2. 단위 변환
3. BMI 계산기
4. 환율 환산
5. 연봉 실수령
6. 부가세 10%
7. 더치페이 1/N
8. 칼로리(BMR)
9. QR코드 생성
10. 글자수 세기
11. 나이(만나이)
12. 디데이
13. 대출 이자
14. 퍼센트/할인
15. 비밀번호 생성
16. 알람/타이머
17. 세계 시계
18. 컬러 피커
19. 임신 주수
20. 날짜 계산 / 스톱워치

## SEO / GEO

- `robots.txt`, `sitemap.xml`, canonical, Open Graph, JSON-LD(`WebSite`, `ItemList`, `FAQPage`)
- `llms.txt`로 생성형 검색(GEO) 인용용 요약 제공
- 도구 전환 시 `document.title`과 description 갱신
- GPTBot, Google-Extended, ClaudeBot, PerplexityBot 허용

## 구글 애드센스

1. AdSense 승인 후 `js/config.js`의 `adsenseClient`, 슬롯 ID를 넣고 `adsenseEnabled: true`
2. `ads.txt`의 `pub-XXXXXXXXXXXXXXXX`를 본인 퍼블리셔 ID로 변경
